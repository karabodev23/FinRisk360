# FinRisk360 — Banking Risk & Compliance Management System

FinRisk360 is a full-stack banking risk and compliance management system built with ASP.NET Core Web API, Entity Framework Core, SQL Server, and React.

The system allows users to manage customer risk cases, track fraud and compliance investigations, assign cases to departments, calculate risk scores, view dashboard analytics, and maintain audit logs.

## Tech Stack

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
- Clean Architecture
- Layered Class Libraries

### Frontend
- React
- Axios
- Recharts
- CSS
- Role-based UI
